Select Game Data Root Folder

The selected grid contains a GridDataPath. Choose the root folder on your drive that contains the folders referenced by GridDataPath. For example, if your files can be under both GridData and SceneLayouts, select their common parent directory — not either child folder.

The Suite reads the GridDataPath values already present in the Grids list and resolves only those paths under this root. It does not scan or load unrelated JSON files.
