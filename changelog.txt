Version 3.7
-----------

Current Development Rules
-------------------------
- Keep source code readable and properly formatted.
- Avoid unnecessary minification/compression of source code.
- Preserve existing working functionality unless a change specifically replaces it.
- Continue explicit Dreamlight Save Suite version numbering.
- For future updates, provide ONLY the file(s) that were actually modified instead of packaging the entire project structure.
- If one file changes, provide that file only.
- If multiple files change, provide only those changed files.

General Grid Reference Design
-----------------------------
The current intended Grid reference workflow is:

    Select Root Folder
          |
          v
    Select Grid object
          |
          v
    Read GridDataPath
          |
          v
    Resolve path beneath root
          |
          v
    Prefer non-_BlockSpawn equivalent
          |
          v
    Open only required file
          |
          v
    Decode on demand
          |
          v
    Validate reference
          |
          v
    Display reference layer

This approach is intended to keep the Suite responsive while avoiding unnecessary
directory-wide decoding and reducing the chance of displaying an incorrect reference layer.
